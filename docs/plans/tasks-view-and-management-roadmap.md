# Roadmap: просмотр и управление задачами (web + JVM)

Дата: 2026-11-23. Цель: выпустить работающую платформу для web и JVM. Принят январский релиз 2027 с учётом каникул 31.12.2026–10.01.2027.

## Принятые ограничения

- Первый эпик (#105) реализует только просмотр: список и детали задачи.
- Второй эпик (#125) реализует управление: действия, параметры и создание задачи.
- В каждом эпике есть работа и для web, и для JVM.
- Платформенные лейблы: `web` — для web-задач; `macos` и `windows` — для JVM-задач.
- Лимит ёмкости — **40 SP на итерацию** (агрессивный режим, выше исторической скорости 12–16 SP/нед).
- Праздники РФ: **31.12.2026–10.01.2027** нерабочие, первый рабочий день — 11.01.2027. В Iteration 38 только 8 рабочих дней.
- Milestone ставится только на User Story; Task наследует принадлежность через родителя.
