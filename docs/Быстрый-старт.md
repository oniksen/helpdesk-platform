# Быстрый старт

## Требования

- JDK 21
- Gradle (используется wrapper)

## Запуск

### Web (Wasm — быстрее)

```bash
./gradlew :webApp:wasmJsBrowserDevelopmentRun
```

### Web (JS — для старых браузеров)

```bash
./gradlew :webApp:jsBrowserDevelopmentRun
```

## Тесты

```bash
# Wasm
./gradlew :shared:wasmJsTest

# Все тесты
./gradlew allTests
```

## Линтер

```bash
./gradlew detekt
```
