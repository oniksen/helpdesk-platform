# Добавление фичи

## Пошаговая инструкция

### 1. Создать модуль API

Создать `features/<name>/api` с маршрутом:

```kotlin
// features/<name>/api/src/commonMain/kotlin/navigation/<Name>ScreenRoute.kt
package navigation

import androidx.navigation3.runtime.NavKey
import kotlinx.serialization.Serializable

@Serializable data object <Name>ScreenRoute : NavKey
```

### 2. Создать модуль impl

Создать `features/<name>/impl` с `FeatureNavModule` и экранами:

```kotlin
// features/<name>/impl/src/commonMain/kotlin/navigation/<Name>Module.kt
package navigation

class <Name>Module : FeatureNavModule {
    override val serializerModule = SerializersModule {
        polymorphic(NavKey::class) {
            subclass(<Name>ScreenRoute::class, <Name>ScreenRoute.serializer())
        }
    }

    override fun canResolve(key: NavKey): Boolean = key is <Name>ScreenRoute

    override fun resolve(key: NavKey, onBackPressed: () -> Unit): NavEntry<out NavKey> =
        NavEntry(key = key as <Name>ScreenRoute) {
            <Name>Screen()
        }
}
```

### 3. Зарегистрировать модуль в DI

```kotlin
// core/di/src/commonMain/kotlin/DiProvider.kt
private val navigationModule = module {
    single<FeatureNavModule> { <Name>Module() }
}
```

### 4. Добавить модули в settings.gradle.kts

```kotlin
include(":features:<name>")
include(":features:<name>:api")
include(":features:<name>:impl")
```

### 5. Добавить зависимости в build.gradle.kts

В `features/<name>/api/build.gradle.kts`:
```kotlin
implementation(projects.core.navigation.api)
```

В `features/<name>/impl/build.gradle.kts`:
```kotlin
implementation(projects.features.<name>.api)
implementation(projects.core.navigation.api)
```
